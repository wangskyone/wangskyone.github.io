# Tianyi Wang's Homepage

Source for [wangskyone.github.io](https://wangskyone.github.io/), built with Jekyll and the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme.

The current design was adapted from [jiazhou-garland/jiazhou-garland.github.io](https://github.com/jiazhou-garland/jiazhou-garland.github.io). Theme-derived code is provided under the included CC0 1.0 license.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://127.0.0.1:4000/>.
